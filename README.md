# Cisco Packet Tracer 9.0 on openSUSE

This repository documents a manual installation of Cisco Packet Tracer 9.0
on openSUSE using the official Debian package provided by Cisco.

The focus is on:
- extracting the `.deb` manually
- handling activation and desktop integration
- resolving KDE / Qt issues that prevent browser-based login

## Documentation

The full step-by-step guide is available here:

- [Manual installation guide (HTML)](docs/packet-tracer-9-opensuse.html)

## Notes

This approach was tested on openSUSE Tumbleweed with KDE Plasma.
Packet Tracer 9.x is distributed as an AppImage and installs under `/opt/pt`.
